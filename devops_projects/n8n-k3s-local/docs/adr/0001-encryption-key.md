# Общий ключ шифрования для ролей n8n

Все роли n8n внутри одного окружения получают `N8N_ENCRYPTION_KEY` из одного существующего Kubernetes Secret. Staging и production используют разные Secret и ключи. Генерация ключа при каждом Helm-деплое или отдельный ключ на worker сделали бы сохранённые credentials недоступными; поэтому дамп PostgreSQL восстанавливается только вместе с исходным ключом. Secret создаётся оператором вне чарта и не попадает в Git.
