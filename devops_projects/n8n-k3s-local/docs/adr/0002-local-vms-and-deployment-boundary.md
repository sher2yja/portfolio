# Локальные VM и граница Ansible/Helm

До появления внешней инфраструктуры приложение работает на локальной VM k3s, а GitHub Actions runner — на отдельной VM без общей папки с хостом. Vagrant создаёт машины, Ansible повторяемо настраивает k3s, мониторинг и таймеры копий; Helm через GitHub Actions владеет релизами n8n. Такое разделение позволяет автоматически обновлять staging после push, не повторяя подготовку хоста и не выдавая runner административный kubeconfig. Публичный TLS и VPS в этой конфигурации не заявлены.
