# Без публичного ingress на локальном этапе

Первоначальный вариант с ingress-nginx и HTTPS заменён локальным доступом через `kubectl port-forward`: VPS и домена нет. Это не имитация публичного TLS — внешние webhook и срок сертификата здесь не проверяются. При переносе на публичный сервер решение о контроллере ingress и сертификатах нужно принять заново.
