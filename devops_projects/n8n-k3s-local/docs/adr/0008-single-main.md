# Один main как принятый риск

В каждом окружении оставлен один main: он предоставляет редактор и отвечает за расписание. Это экономит ресурсы локальной VM, но во время его отказа cron-триггеры могут не сработать; webhook и worker не делают планировщик отказоустойчивым. Риск принят для учебного стенда и должен быть виден в мониторинге, а не скрыт обещанием высокой доступности.
