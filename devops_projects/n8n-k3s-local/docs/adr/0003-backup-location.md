# Копии вне VM, но пока на одном ПК

Production-копия хранится вне VM и Git в закрытом каталоге хоста: потеря VM не должна уничтожать дамп, ключ и применённые Helm values одновременно. Скрипт оставляет 14 последних проверенных копий; ручная проверка восстанавливает последний дамп во временный PostgreSQL. Автоматические таймеры удалены по решению владельца после успешного опыта, поэтому новая копия появится только после ручного запуска сервиса. Дополнительно один снимок зашифрован GPG AES-256 на USB и проверен распаковкой и SHA-256. Новые снимки нужно переносить на USB отдельно, а парольную фразу хранить независимо от ПК и носителя.
