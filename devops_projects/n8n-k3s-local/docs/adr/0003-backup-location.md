# Копии вне VM, но пока на одном ПК

Production-копия хранится вне VM и Git в закрытом каталоге хоста: потеря VM не должна уничтожать дамп, ключ и применённые Helm values одновременно. Оставляются 14 последних проверенных копий; еженедельная проверка восстанавливает дамп во временный PostgreSQL. Дополнительно один снимок зашифрован GPG AES-256 на USB и проверен распаковкой и SHA-256. Это не делает ежедневные копии автоматически внешними: новые снимки нужно переносить на USB отдельно, а парольную фразу хранить независимо от ПК и носителя.
