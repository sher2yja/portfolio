# Персистентность Redis

Redis работает отдельным StatefulSet с PVC на 1 ГиБ, чтобы данные очереди не исчезали только из-за пересоздания Pod. Это снижает риск, но не доказывает гарантированного повторного выполнения: при принудительной потере worker один опыт закончился ошибкой задания. Для гарантии потребуются отдельная политика повторов и повторный отказный тест.
