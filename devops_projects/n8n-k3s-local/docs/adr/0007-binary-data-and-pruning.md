# Бинарные данные в PostgreSQL и автоочистка исполнений

Для queue mode выбран `N8N_DEFAULT_BINARY_DATA_MODE=database`, чтобы роли n8n не зависели от общего локального каталога файлов. История исполнений автоматически очищается через `EXECUTIONS_DATA_PRUNE=true` и `EXECUTIONS_DATA_MAX_AGE=168` часов; иначе одна VM могла бы постепенно заполнить PostgreSQL и диск. Отдельное объектное хранилище не добавлено, поскольку стенд работает только локально.
