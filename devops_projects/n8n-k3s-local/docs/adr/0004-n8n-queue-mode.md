# n8n в режиме очередей

n8n выбран как приложение с реальными webhook, фоновыми задачами и встроенным интерфейсом. Отдельные main, webhook и worker работают в queue mode: Redis передаёт задания worker, PostgreSQL хранит состояние приложения. Это даёт проверяемую нагрузку и отказные сценарии без создания искусственных микросервисов; цена — зависимость выполнения от Redis и базы.
