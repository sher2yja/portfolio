# Одна версия n8n для приложения и task runner

`n8n.version` в Helm values задаёт версию официального task runner и базовую версию собственного образа n8n. Образ приложения в CI дополнительно получает неизменяемый тег git SHA. Разные версии main, webhook, worker и runner усложнили бы совместимость при обновлении; перед сменой версии требуется пересобрать образ и проверить staging.
