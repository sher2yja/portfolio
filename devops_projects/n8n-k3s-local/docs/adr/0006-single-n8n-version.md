# Одна версия n8n для приложения и task runner

После переноса в `src/` источник версии релиза — `src/chart/Chart.yaml: appVersion`. Build передаёт эту версию в Dockerfile всех четырёх ролей; официальные базовые образы n8n и runners имеют одинаковый release tag 2.40.7. Собственные образы в CI получают общий тег git SHA. Перед сменой версии требуется пересобрать четыре образа и проверить кандидата.

Внутренние npm-пакеты upstream имеют отдельные версии: например, официальный runners:2.40.7 содержит @n8n/task-runner 2.40.3. Версия release image и версия отдельного пакета различаются; вручную менять package.json для совпадения номеров нельзя.
